# C# Module 2 — Object-Oriented Programming

Lessons and homework from the second module: designing classes and small service layers in C#.

## What's inside

- Classes with service layers: `Car`/`CarService`, `School`/`SchoolService`, `Employee`/`EmployeeService`, `Phone`, `User`, `Book`
- Inheritance and polymorphism: `AirCar`, `HeavyCar`, `Damas`, `Matiz`, `Factory`
- Interfaces and dependency inversion: `ICountryService`, `ISingerService`, `IEmailServise`, `IPayService` with `PayanetService` and `XaznaServise`
- DTOs for create / get / update (`SingerCreateDto`, `SingerGetDto`, `SingerUpdateDto`)
- Extension methods: `StringExtension`, `IntExtensions`, `ExtensionString`

## Tech

C# · .NET console · OOP
